# DocuCamp

Plateforme de partage de documents et de matériel pédagogique.

## Structure

- `frontend/`: application React/Vite
- `backend/`: API Flask
- `database/`: schéma, politiques, index et données initiales

## Démarrage

```bash
cd frontend
npm install
npm run dev
```

Pour l'API :

```bash
cd backend
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python run.py
```
